# Global Sales Analysis using Power BI

## Project Overview
This project analyzes global sales data using Microsoft Power BI. The dashboard presents sales and profit performance through visualizations to help understand business trends.

## Tools Used
- Microsoft Power BI
- Data Analysis and Visualization

## Project Objectives
- Analyze overall sales and profit performance.
- Identify sales trends across different regions.
- Understand product sales performance.
- Present business information through interactive visualizations.

## Key Features
- Sales performance analysis
- Profit analysis
- Regional sales comparison
- Product-level analysis
- Interactive dashboard visualizations

## Project File
- `Global-Sales-Analysis using powerBI(1).pbix` – Power BI report file.

## Key Learnings
- Creating dashboards using Power BI.
- Analyzing sales data.
- Presenting business insights through visualizations.
